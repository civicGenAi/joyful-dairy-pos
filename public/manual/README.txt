Screenshots for the user manual.

Drop a PNG in this folder using the exact file name the manual asks for,
and it appears in its place automatically. No code change needed. A slot
with no file yet shows a labelled frame telling you what to capture, so an
unfinished manual is still readable and obvious.

Expected files:

  01-signin.png             The sign-in screen
  02-dashboard.png          The dashboard on a normal morning
  03-shortcut.png           The Shortcut panel open
  04-farmers.png            The farmer list
  05-collection.png         Recording a collection, both sessions filled
  06-collection-reject.png  The same form with milk refused
  07-farmer-pay.png         Paying a farmer
  08-pos.png                Counter POS mid sale
  09-route-load.png         The van load tab, confirmed
  10-route-sell.png         Selling on the route
  11-route-cashup.png       The cash-up tab
  12-customers.png          The customer list
  13-customer-credit.png    A customer with a credit limit set
  14-production.png         Recording a batch
  15-stock.png              Stock and store, showing stock value
  16-morning-count.png      The morning count
  17-day-close.png          Day reconciliation, ready to lock
  18-expenses.png           Expenses with the place breakdown
  19-sales-deposits.png     Sales deposits for a month
  20-books-pl.png           Books, profit and loss
  21-books-balance.png      Books, balance sheet
  22-books-vat.png          Books, VAT return
  23-books-bank.png         Books, bank reconciliation
  24-payroll.png            Payroll for a month
  25-reports.png            Reports

Capture at a normal laptop window size. Avoid showing a real customer's
full balance if the manual will be shared outside the dairy.
